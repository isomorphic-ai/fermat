## 2026-07-29 — C3 has a clean generated algebraic core and one arithmetic input

- Vandiver's final unit-power argument is independent of cyclotomic
  enumeration.  For the edge family generated by one cycle, finite index
  supplies a power/product relation; primitive normalization, the
  coefficient congruences, and Bézout then construct a `p`-th root.
- This algebraic core can be reconstructed under the credit namespace from
  Mathlib alone and credited explicitly to Vandiver's Lemma II.  It will be
  specialized to the cycle's edge family, rather than accepting an arbitrary
  hidden unit provider.
- The irreducible C3 arithmetic input is narrower than "repayment": a deep
  local congruence must imply the coefficient-cube congruences for every
  primitive generated relation.  The rung must name this input exactly.
  Supplying a power root, a repayment function, or an endpoint proposition
  would conceal the obligation and is not acceptable.

## 2026-07-29 — capacity is an index only after its ambient boundary is explicit

- `Subgroup.relIndex` is the useful route-neutral representation of
  capacity, but it is defined using intersection and returns zero at infinite
  index.  A capacity object therefore needs the generated sub-ledger, the
  ambient ledger, a proof that the former lies in the latter, and finite
  relative index before it may be described as finite capacity.
- A numerical determinant can check an index fact only after a realization
  map connects its columns to the generated edge family.  This adapter and
  the determinant/index theorem are part of C2's certificate boundary; the
  matrix itself cannot define either the family or its capacity.

## 2026-07-29 — one cycle generates the matrix, the unit family, and both sides

- The useful route-neutral generator is a cycle with `rank + 1` nodes.  Its
  `rank` successive edge ratios generate the sub-ledger.  This matches a
  unit rank of 28 with a Galois cycle of order 29 without supplying 28
  independent seeds.
- The credit matrix is a node-pair matrix whose entries are sets of
  generators.  Pointwise union is its semilattice merge.  Transposition is
  the receivable view of the same matrix, so two-sidedness requires no second
  collection of data.
- C1 is consequently absence of a funded generator: when the generator type
  is empty, the generated matrix is bottom.  It is not a separately asserted
  table of zero entries.
